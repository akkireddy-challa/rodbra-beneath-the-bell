# Skybox Generation

When players want to change the visual atmosphere, background, or overall look and feel of their game world, use the skyboxGenerationTool:
- For requests like "make it look more futuristic", "change the background to a forest", "create a cyberpunk atmosphere"
- For environmental mood changes like "make it darker", "add a sci-fi feel", "create a fantasy setting"
- The tool generates seamless 360-degree panoramic skyboxes that automatically integrate with the game's world configuration
- Skyboxes provide dramatic visual transformation without requiring complex 3D modeling or asset management
- Examples: "cyberpunk city with neon lights", "mystical forest with floating islands", "alien space nebula with distant planets"
